# The phase template

Copy this. Fill every field. A field you cannot fill is a question you have to
ask the client before the phase starts, not a detail to settle later.

## English

```
Phase <n> - <name>

in:            <what you receive, in what format, with what limits>
out:           <what exists at the end that did not exist before>
payment:       <what this phase releases, and when>
done when:     <an observable event, written before the work starts>
signed off by: <named person>, within <n> business days. If <name> is
               unavailable it is approved automatically and payment is released.
not included:  <the neighbouring work this phase does not cover>
```

## Hebrew

```
שלב <n> - <שם>

נכנס:      <מה אתה מקבל, באיזה פורמט, עם אילו מגבלות>
יוצא:      <מה קיים בסוף שלא היה קיים קודם>
תשלום:     <מה השלב הזה משחרר, ומתי>
גמור כש:   <אירוע שניתן לצפות בו, נכתב לפני שהעבודה מתחילה>
מי מאשר:   <שם מלא>, עד <n> ימי עסקים. אם <שם> לא זמין/ה זה מאושר
           אוטומטית ומועבר תשלום.
לא כלול:   <העבודה השכנה שהשלב הזה לא מכסה>
```

## The one line that goes above all the phases

```
Changes to an agreed phase are quoted separately. They do not move the current
phase's acceptance criterion or its date.
```

```
שינויים בשלב שסוכם מתומחרים בנפרד. הם לא מזיזים את קריטריון הקבלה של השלב
הנוכחי ולא את התאריך שלו.
```

## Checklist before you send it

- [ ] Does **in** have a limit on it (size, count, format, number of sources)?
- [ ] Is **out** a noun, not an activity?
- [ ] Would you and the client read **done when** the same way? Read it back to
      yourself as if you wanted to argue with it.
- [ ] Is **signed off by** a named human, with a deadline **and** a default if
      the deadline passes?
- [ ] Does **not included** list the things a reasonable person would assume are in?
- [ ] Does each phase deliver something usable on its own?
- [ ] Is the previous phase closed before this one opens?
